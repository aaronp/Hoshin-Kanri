# Acme plan — X-Matrix data repo template

Copy this directory into a new repo to publish your own Hoshin Kanri X-Matrix.
This repo holds only data; the UI comes from
[aaronp/Hoshin-Kanri](https://github.com/aaronp/Hoshin-Kanri).

1. Edit `x-matrix.md` (format is shown in the viewer's Markdown panel).
2. Push to `main`, then Settings → Pages → Source: **GitHub Actions**.
3. Open `https://<you>.github.io/<repo>/` — it redirects to the viewer with
   `?src=` pointing at your `x-matrix.md`.

No Pages? Link straight to the raw file:
`https://aaronp.github.io/Hoshin-Kanri/?src=https://raw.githubusercontent.com/<you>/<repo>/main/x-matrix.md`
